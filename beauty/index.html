Beauty.css

Легкая CSS-библиотека для красивых сайтов, которые приятно читать. Типографика, формы и темная тема для обычного HTML. На этой странице — примеры всех ее возможностей.

Подключение

Скачайте CSS-файл и подключите его в <head>:

<link rel="stylesheet" href="beauty.min.css">

Или установите пакет для проекта со сборщиком:

npm install beauty-css
import "beauty-css";

Примеры и файлы для скачивания — из версии 0.5.0-dev.0. Она может быть новее версии в npm. На этой странице используются шрифты и настройки блога; сама библиотека не содержит шрифтов или JavaScript.

Типографика

Обычный HTML уже выглядит хорошо. Классы нужны только для дополнительных акцентов.

Дополнительные подробности

Что работает без JavaScript?

Типографика, системная тема, формы, фокус и этот блок. Скрипт на странице только переключает тему и помогает копировать примеры.

HTML примера
<details>
  <summary>Что работает без JavaScript?</summary>
  <p>Типографика, системная тема, формы, фокус и этот блок. Скрипт на странице только переключает тему и помогает копировать примеры.</p>
</details>

Prose

Для отдельного блока на существующем сайте используйте prose вместо версии для всей страницы. Стили действуют внутри .beauty. Класс .not-beauty исключает встроенный компонент; обычное наследование шрифтов и цветов сохраняется.

<link rel="stylesheet" href="beauty.prose.min.css">

<article class="beauty">
  <h1>Заголовок</h1>
  <p>Текст.</p>
  <div class="not-beauty">Ваш виджет</div>
</article>
