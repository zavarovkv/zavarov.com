Beauty.css

A lightweight CSS library for beautiful, readable websites. Typography, forms and dark mode for plain HTML. This page demonstrates all its features.

Get started

Download the stylesheet and add it to <head>:

<link rel="stylesheet" href="beauty.min.css">

Or install the package for a project with a bundler:

npm install beauty-css
import "beauty-css";

Examples and downloads use version 0.5.0-dev.0. It may be ahead of npm.

Prose

To style a single block on an existing site, use prose instead of the whole-page version. Styles apply inside .beauty. The .not-beauty class excludes an embedded component; ordinary font and color inheritance remains.

<link rel="stylesheet" href="beauty.prose.min.css">

<article class="beauty">
  <h1>Heading</h1>
  <p>Text.</p>
  <div class="not-beauty">Your widget</div>
</article>
