17 live HTML examples

One file. Ready to go.

For a new page, use the classless version. Download the file and add this line to <head>:

<link rel="stylesheet" href="beauty.min.css">

For an existing website, use only prose and a container .beauty:

<link rel="stylesheet" href="beauty.prose.min.css">

<article class="beauty">
  <h1>Your heading</h1>
  <p>Your words.</p>
</article>

Download prose · See scoped styles

Install with npm
npm install beauty-css
import "beauty-css";
// Or just a container:
import "beauty-css/prose";

These examples show version 0.5.0-dev.0. Download CSS from this page to get the exact same styles. The npm version may differ.

Inside your website

Prose styles only the contents of .beauty. Exclude an embedded widget with .not-beauty; ordinary font and color inheritance still applies.

<article class="beauty" data-theme="light">
  <p>Styled text.</p>
  <div class="not-beauty">Independent component</div>
</article>

Make it yours

Override public variables. Your normal styles take priority over the beauty layer, so ordinary customization needs no !important.

:root {
  --beauty-link: #7250a5;
  --beauty-reading-width: 42.5rem;
}

/* For prose, set variables on the container. */
.beauty { --beauty-line-height: 1.7; }
