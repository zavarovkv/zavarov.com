17 живых примеров с HTML

Один файл — и готово

Для новой страницы используйте версию без классов. Скачайте файл и добавьте эту строку в <head>:

<link rel="stylesheet" href="beauty.min.css">

Для существующего сайта — только prose и контейнер .beauty:

<link rel="stylesheet" href="beauty.prose.min.css">

<article class="beauty">
  <h1>Ваш заголовок</h1>
  <p>Ваш текст.</p>
</article>

Скачать prose · Посмотреть изоляцию стилей

Установка через npm
npm install beauty-css
import "beauty-css";
// Или только контейнер:
import "beauty-css/prose";

Примеры показывают версию 0.5.0-dev.0. Чтобы получить точно такие же стили, скачайте CSS с этой страницы. Версия в npm может отличаться.

Внутри вашего сайта

Prose оформляет только содержимое .beauty. Встроенный виджет можно исключить классом .not-beauty; обычное наследование шрифтов и цветов сохраняется.

<article class="beauty" data-theme="light">
  <p>Стилизованный текст.</p>
  <div class="not-beauty">Независимый компонент</div>
</article>

Навигация без лишней разметки

В версии без классов header, nav и footer получают базовую компоновку. beauty-nav-end прижимает последний элемент к краю. Верхнее меню этой страницы использует тот же класс.

<header>
  <nav>
    <strong>Проект</strong>
    <a href="#about">О проекте</a>
    <a class="beauty-nav-end" href="/login">Войти</a>
  </nav>
</header>
