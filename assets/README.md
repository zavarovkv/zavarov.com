# Site assets

- Site-owned files mounted into Hugo's asset pipeline.
- `css/site-navigation.css` styles the blog's account icon and Telegram menu link.
- `css/resume.css` styles only the blog's custom CV; its template lives in `layouts/resume/single.html`.
- Shared styles, scripts and bundled fonts belong to `themes/hugo-mini`.
- Licensed fonts stay in ignored `private-fonts/`; never commit them or secret bundles.
