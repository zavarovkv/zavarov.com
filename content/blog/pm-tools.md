Хочу поделиться сервисами и программами, которые я использую (постоянно) в решении рабочих задач. Возможно, вы откроете для себя что-то новое и сделаете свою работу комфортнее.

<h2>Продуктовая насмотренность и UX</h2>

- [ProductHunt](https://www.producthunt.com/) — ключевой сервис для развития общей продуктовой насмотренности, позволяет держать руку на пульсе запусков новых продуктов и развития существующих.
- [UserOnboard](https://www.useronboard.com/) — библиотека с подробными разборами UX популярных сервисов, например, Gmail, Instagram, Apple Music, Netflix, etc.

<h2>Исследования и A/B-тесты</h2>

- [Statista](https://www.statista.com/) — база знаний с актуальной аналитикой и исследованиями рынков. Здорово, если есть корпоративный аккаунт с доступом к подробным отчетам, но и бесплатная версия позволяет просматривать базовые отчеты.
- [Яндекс Вордстат](https://wordstat.yandex.com/) — помогает проанализировать запросы пользователей в ру-сегменте интернета.
- [ResearchGate](https://www.researchgate.net/) — огромное библиотека научных статей по любой теме.
- [Evan’s Awesome A/B Tools](https://www.evanmiller.org/ab-testing/) — один из старейших и самый популярный сервис в интернете для планирования и анализа AB-тестов: оценки размеров выборки и результатов экспериментов.
- [GoodUI](https://goodui.org/) — библиотека паттернов с AB-тестами и разборами их результатов.

<h2>Схемы, диаграммы и графика</h2>

- [Miro](https://miro.com) — стандарт де-факто для визуального письма.
- [Mermaid](https://mermaid.js.org/) — сервис для построения диаграмм по текстовому описанию (коду). Поддерживает интеграцию в большое кол-во современных wiki-систем: notion, g-docs, confluence.
- [Draw.io](https://www.drawio.com/) — простой и удобный сервис для создания более сложных схем и диаграмм, чем позволяет создавать Mermaid. Позволяет сохранять исходник на g-диске и не требует ни регистрации, ни авторизации.
- [Canva](https://www.canva.com/) — лучший инструмент для создания каких-либо графических элементов, для большинства простых задач хватает бесплатной версии.
- [Emojipedia](https://emojipedia.org/) — база эмодзи для добавления щепотки эмоций в описание требований и постановку задач.

<h2>Личная и командная эффективность</h2>

- [Things](https://culturedcode.com/things/) — простой и очень удобный ToDo-лист для Mac и iOS в мнималистичном дизайне и хорошей типографикой для дизайн-перфекционистов.
- [Типографская раскладка Ильи Бирмана](https://ilyabirman.ru/typography-layout/) — удобная раскладка, чтобы писать красивые тексты и печатать правильные знаки и символы быстро (✓≈≠₽x↓−""). Если вы много пишите и стараетесь, чтобы текст выглядел красиво — попробуйте раскладу Бирмана, это кайф.
- [Obsidian](https://obsidian.md/) — приложение для организации заметок в формате Markdown (.md).
- [ChatGPT](https://chatgpt.com/) — замена google-поиску.
- [Google Таблицы, Презентации, Colab](https://google.com) — базовый минимум для любого менеджера.

<h2>Быстрая разработка MVP, вайб-кодинг</h2>

- [Cursor IDE](https://cursor.com/) — редактор кода на стеройдах, который позволяет создавать приложения и сераисы с минимальным уровнем знаний языков программирования, очень быстро.
- [GitHub / GitHub Pages](https://docs.github.com/en/pages) — быстро и бесплатно развернуть статику в проде.
- [Vercel](https://vercel.com/) — быстро и бесплатно развернуть более сложный сервис в проде.
